# 마이페이지와 암호화 프로필

갱신: 2026-11-27.

## 사용자 흐름

- 혜택 둘러보기: 틸 그린 BF 브랜드, 실제 데이터 검색·필터·상세
- 마이페이지 /my: 나이·시도·가구원·자녀 수·혼인·경제활동·주거·장애 여부, 연소득·가구자산·부채, 12개 관심 분야
- 보관 암호를 두 번 입력해 암호화 저장
- 나의 맞춤 혜택 /recommended: 암호로 잠금 해제 후 관련 후보·추천 이유 표시
- 프로필 수정·전체 삭제 지원

모든 프로필 항목은 선택 사항이다. 한 가지 이상의 정보 또는 관심 분야가 있어야 저장한다.
서비스 데이터가 아직 없는 분야는 전체 범위를 제공한다고 표시하지 않는다.

## 암호화 및 개인정보 흐름

현재는 계정 없는 로컬 프로토타입이다. 서버 저장·로그인·기기 간 동기화는 없다.
Web Crypto의 AES-256-GCM으로 프로필 JSON을 암호화한다.
암호마다 PBKDF2-SHA256(310,000회), 무작위 16바이트 salt 및 12바이트 IV를 사용한다.
암호화 키는 추출 불가로 생성하고 키·암호를 브라우저 저장소에 보관하지 않는다.
저장소에는 버전·알고리즘·salt·IV·암호문만 기록한다.
기본은 sessionStorage, 명시적으로 계속 저장을 선택하면 localStorage다.
프로필이나 암호를 HTTP 요청·쿼리·외부 AI에 전송하지 않는다.
추천에 사용하는 공개 제도 카탈로그만 서버에서 받으며 조건 비교는 브라우저에서 실행한다.
JavaScript가 초기화되기 전에는 개인정보 폼 전체가 비활성화된다.

페이지 이동·새로고침 시 다시 잠금 해제해야 한다. 암호를 잊으면 복구할 수 없다.
동일 브라우저 사용자는 암호화 데이터를 삭제할 수 있다. 삭제 후 새 프로필을 입력한다.
암호 해제된 정보는 해당 페이지 메모리에 존재한다. 암호화는 보관 중 데이터를 위한 조치다.
이전 버전 평문 프로필 키가 있다면 새 암호화 저장 또는 전체 삭제 시 제거한다.
실제 서비스의 계정·서버 저장·운영 키 관리·개인정보 정책은 후속 설계 사항이다.

## 후보 정렬

관심 분야 키워드, 명시적 지역 메타데이터, 원천의 제한된 연령 범위·생애주기,
자녀·주거·경제활동·장애 관련 안내를 이용한 단순 연관성 점수다.
추천 이유에 사용한 항목을 표시하며 점수를 자격 확률로 표현하지 않는다.
지원 조건을 승인한 규칙 엔진이나 LLM 개인별 판정이 아니다.
모르는 조건 또는 연령이 맞지 않는다는 이유로 전체 검색에서 제도를 제외하지 않는다.
소득·자산·부채·가구원·혼인은 아직 자동 비교하지 않는다. 화면에 명시했다.
소득만 입력하면 관련 후보가 없을 수 있으며 관심 분야 추가·직접 검색을 안내한다.
지역이 다른 후보도 다른 관련 정보가 있으면 나올 수 있다. 실제 적용 지역은 공식 안내에서 확인한다.

## 검색 우선 흐름 (2026-11-27 후속)

사용자 지시에 따라 첫 화면의 제도 목록·전체 건수·기본 페이지 탐색을 제거했다. 빈 검색 화면에서는 카탈로그를 내려받거나 프로필을 해제하지 않는다. 검색 후 프로필이 없으면 입력을 안내하고, 암호화 프로필이 있으면 잠금 해제 후 공개 데이터를 받아 브라우저에서 검색어와 프로필 연관성이 모두 있는 후보만 표시한다. 관련 후보가 없어도 전체 목록으로 대체하지 않는다. 출처·중앙부처 범위 필터를 지원한다. 상세 조건이 부족한 후보는 확인 필요로 표시하며 자격 충족으로 간주하지 않는다. 디자인은 사용자 요청대로 임시 상태를 유지한다.
