# 로컬 검색·상세 화면

## 실행

    cd C:\dev\Bene_Fit
    python scripts/serve_catalog.py

브라우저에서 http://127.0.0.1:8765 를 연다.
종료는 실행 창에서 Ctrl+C. 다른 포트는 --port 8766으로 지정한다.
Python 기본 라이브러리만 사용하며 API를 추가 호출하지 않는다.
127.0.0.1에만 바인딩하며 외부 배포용 서버가 아니다.

## 제공 기능

- 중앙부처 후보 1,509건 기본 탐색
- 전체 16,196건으로 검색 범위 확대
- 검색어·출처 필터, 전체 결과 건수, 20건 단위 페이지 이동
- 출처별 제도 상세, 지원대상·선정기준·내용·신청방법·서류·기한
- 공식 안내·신청처, 법령·서식·문의처
- 목록·상세 조회시각과 항목별 원천 구분
- 상세 수집 대기·미확인 정보 표시

현재 접수 중·자격 충족으로 자동 판정하지 않는다.
중앙부처 출처와 전국 적용 여부는 다르므로 화면에 미검증 상태를 안내한다.
마이홈·LH 공고는 아직 별도이며 이번 제도 화면에는 포함하지 않았다.
정부24·복지로 동명 제도는 합치지 않는다.

## 검증

    python scripts/test_web.py

HTTP로 목록·페이지 이동·출처 필터·검색 결과 없음·잘못된 입력·상세·404 응답,
HTML 이스케이프, 위험 링크 제외, .env 및 DB 직접 접근 차단을 검증했다.
실제 DB의 검색·상세 응답도 HTTP 200으로 확인했다.
누락된 조회시각이 있는 데이터도 정상 표시한다.
브라우저 자동화 도구 초기화 실패로 시각적·모바일 화면 검증은 미수행이다.

API 키를 사용하는 경로는 없으며 고정된 HTML 경로만 제공한다.
검색은 기존 공통 정규화 함수와 SQLite 읽기 전용 연결을 사용한다.
