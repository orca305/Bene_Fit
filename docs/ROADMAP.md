# 진행 계획

기준일: 2026-11-27.

| 단계 | 상태 | 결과·완료 기준 |
|---|---|---|
| 0-1 방향 정리 | 완료 | 주거·복지, 전국 공통 우선, 지역 확장, 대전 지인 검증 |
| 0-2 공식 소스 문서 조사 | 1차 완료 | 복지로 중앙부처·정부24·LH 기능과 한계 문서화 |
| 0-3 실제 샘플 수집 검증 | 1차 완료 | 7개 API 확인, 16,196개 제도 정규화. 중앙부처 상세 88/461건, 나머지는 요청 한도로 보류 |
| 0-4 MVP 제도·요구사항 확정 | 초안 | 샘플 결과로 제도 목록과 제공 가능 기능 확정 |
| 0-5 상세 설계 | PostgreSQL 첫 설계·이전 완료 | 약칭 ERD·18개 테이블·규칙 승인 제약을 실제 PostgreSQL 17에 적용. 원문/조건 적재 및 웹 읽기 전환·백업 복원 검증 통과 |
| 1 데이터 기반 구현 | 진행 중 | 원문·버전·검색 조각·초안 보관 구현. 수집 후 로컬 처리 명령과 벡터 재사용 추가. 정기 수집·상세 전량 확보는 미완료 |
| 2 검색 MVP | 진행 중 | 검색·상세·출처·BGE-M3 의미 검색 시험 연결. 전체 임베딩 생성·전체 검색 평가·생성형 답변은 미완료 |
| 3 개인화·조건 분석 | 일부 구현 | 선택형 가족 질문·브라우저 암호화·관련 후보 정렬 구현. 승인 규칙 0개, 실제 자격 판정은 미구현 |
| 4 RAG 개선·사용성 검증 | 미착수 | 계층·시점 검색 효과 측정, 대전 지인 피드백 |
| 5 지역 확장·고도화 | 미착수 | 지역 사업, 관심 저장·비교·알림 등 |

평가·추적은 마지막에 추가하는 별도 단계가 아니라 각 구현 단계와 함께 진행한다. 공식 API 문서 조사는 실제 수집 검증 완료로 간주하지 않는다.
