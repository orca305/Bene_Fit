# 진행 계획

기준일: 2026-11-26.

| 단계 | 상태 | 결과·완료 기준 |
|---|---|---|
| 0-1 방향 정리 | 완료 | 주거·복지, 전국 공통 우선, 지역 확장, 대전 지인 검증 |
| 0-2 공식 소스 문서 조사 | 1차 완료 | 복지로 중앙부처·정부24·LH 기능과 한계 문서화 |
| 0-3 실제 샘플 수집 검증 | 미착수 | API 응답·원문 연결·파싱·조건 근거를 재현 |
| 0-4 MVP 제도·요구사항 확정 | 초안 | 샘플 결과로 제도 목록과 제공 가능 기능 확정 |
| 0-5 상세 설계 | 일부 초안 | 기술 선정, 데이터 모델, 규칙 스키마, API·화면, 개인정보 정책 |
| 1 데이터 기반 구현 | 미착수 | 원문·버전·회차·수집 이력 관리 |
| 2 검색 MVP | 미착수 | 검색·상세·출처·기본 RAG 및 평가 기준선 |
| 3 개인화·조건 분석 | 미착수 | 프로필·추천·승인 규칙·추가 질문 |
| 4 RAG 개선·사용성 검증 | 미착수 | 계층·시점 검색 효과 측정, 대전 지인 피드백 |
| 5 지역 확장·고도화 | 미착수 | 지역 사업, 관심 저장·비교·알림 등 |

평가·추적은 마지막에 추가하는 별도 단계가 아니라 각 구현 단계와 함께 진행한다. 공식 API 문서 조사는 실제 수집 검증 완료로 간주하지 않는다.
