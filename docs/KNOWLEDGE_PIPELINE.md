# 원본·검색 조각·조건 저장 파이프라인

## 실행

    python scripts/build_knowledge.py build
    python scripts/build_knowledge.py search 한부모 --limit 3
    python scripts/test_knowledge.py

외부 API·모델 호출 없이 기존 수집 데이터를 처리한다.
기존 data/collection 및 data/normalized 파일을 수정하지 않는다.

## 저장 구조

data/knowledge/knowledge.sqlite:
- documents: 원천 ID·내용 해시·현재 버전 표시, 원천 레코드 스냅샷, 정규화 필드, 공식 URL·조회시각·원천 파일 위치
- chunks: 검색용 텍스트, 문서 ID, 필드 내 정확한 시작/끝 위치, 앞뒤 조각 ID
- condition_drafts: 조건 검토 초안, 후보 비교식·단위, 근거 조각 ID
- condition_groups: 조건 묶음, AND/OR/예외 등 관계의 원문 표현, 미확정 논리식

data/knowledge/embedding_jobs.jsonl:
- 조각 ID·문서 ID·필드·검색 입력·입력 해시
- status는 pending_model_selection. 아직 벡터를 만들지 않았다.

data/knowledge/summary.json:
- 현재 처리 건수·조각·조건 초안·저장 버전 수

이 데이터는 모두 Git 제외다. 개인 프로필은 입력으로 사용하지 않는다.

## 원본 보존과 버전

수집 API 레코드를 그대로 스냅샷에 넣고 정규화 필드를 함께 보관한다.
정부24는 목록·상세·지원조건의 동일 원천 ID를 연결한다.
복지로는 확보한 상세에 한해 XML 원문·중첩 구조도 함께 들어간다.
기존 수집에서 XML 원문을 보관하지 않은 목록은 추출 API 레코드만 있다.
외부 공고·첨부 원문 다운로드까지 완료했다는 뜻이 아니다.

내용 해시로 버전을 구분하며 재빌드해도 이전 문서·조각·조건은 삭제하지 않는다.
검색과 임베딩 대기 출력은 현재 버전만 사용한다.
새 API 수집 결과를 반영하려면 catalog.py build 후 이 파이프라인을 실행한다.
전체 빌드는 DB 트랜잭션으로 적용하며 실패하면 기존 현재 버전 상태로 돌아간다.
동시 빌드는 지원하지 않는다. 임베딩 대기 파일은 DB 커밋 후 교체한다.
중간 종료로 출력이 누락되면 같은 명령을 재실행한다.

## 문서 분할

지원대상·선정기준·지원내용·신청방법·서류·기간·법령을 필드별로 분리한다.
분류 코드는 별도 필드로 보존한다.
최대 1,100자, 문장 경계를 우선하고 최대 180자 문맥을 중첩한다.
기준은 토큰 수가 아닌 문자 수다. 모델 선택 후 토큰 한도를 확인해야 한다.
검색 입력에 제도명·기관·필드명을 덧붙여 문맥을 제공한다.
locator는 원문 페이지 번호가 아니라 정규화 필드의 문자 위치임을 명시한다.
표·예외가 여러 조각에 걸칠 수 있어 앞뒤 조각 및 전체 부모 필드를 함께 조회해야 한다.

## 조건 초안

기존 코드·본문 단서에 더해 숫자+단위+이상/이하/초과/미만 표현을 추출한다.
숫자 표현의 비교식 후보만 저장하며 누구의 나이·자녀 수·금액인지 자동 확정하지 않는다.
원천 코드의 Y를 필수조건으로, null을 제외조건으로 해석하지 않는다.
조건은 모두 draft, 적용 대상 unresolved, usable_for_eligibility false다.
AND/OR·예외·제외·중복 표현을 원문 위치와 함께 보존하지만 실제 관계식은 null이다.
한 문서에 여러 지원 유형·우선순위·예외가 있으므로 이를 검토하기 전에는 실행하지 않는다.

## 현재 검색과 다음 단계

search 명령은 근거 추적을 검증하는 키워드 검색 기준선이다.
아직 벡터 검색·RAG 생성·사용자 자격 필터로 연결하지 않았다.
다음은 임베딩 모델 선정 → 벡터 생성 → 키워드·벡터 검색 비교 → 조건 검토·승인이다.
개인정보를 외부 모델로 전송하는 기능은 추가하지 않았다.

## 검증

정확한 조각 위치·전체 문자 범위 보존·문맥 연결·조건 근거·미승인 상태를 검증한다.
실제 빌드에서는 DB 무결성과 외래키도 확인한다.
가족 탐색 화면과 암호화 저장 기능은 이 작업에서 변경하지 않는다.
