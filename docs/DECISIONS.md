## 후속 사용자 방향 (2026-11-27)

- 대표 색상은 틸 그린, BF 로고와 친근함·신뢰·동반자 이미지.
- 마이페이지에서 연령·지역·관심 복지·소득·자산·자녀 등 상세 프로필을 입력·수정하고 관련 혜택을 자동 탐색한다.
- 개인정보는 암호화해 보관한다. 로컬 프로토타입은 사용자 암호로 브라우저 암호화 저장을 구현했다. 서버 저장·계정 방식은 미확정이다.
- 생활 혜택 전체 분야는 장기 확장 방향으로 보존한다. 현재 데이터로 제공 가능한 범위를 표시한다.

## 임베딩 모델 확정 (2026-11-27)

사용자 선택: BAAI/bge-m3. 리비전 5617a9f61b028005a4858fdac845db406aefb181, 1,024차원, L2 정규화. CPU 기준 float32·4스레드·배치 2. 설정은 config/embedding.json. KURE-v3 다운로드 파일과 비교 벡터는 사용자 지시에 따라 삭제하고 비교 수치·보고서는 보존한다.

## 데스크탑 이전·PostgreSQL 확정 (2026-11-27)

- 임베딩 생성은 사용자 지시에 따라 중단하고 생성 벡터를 삭제했다. 집 데스크탑(RTX 4070 12GB/RAM 32GB)에서 새 모델을 비교·선택한다. 기존 BGE 설정은 과거 실행 설정이며 새 운영 모델 확정은 아니다.
- 사용자 확정: PostgreSQL로 DB를 설계한다. SQLite 기반 원문·프로토타입은 이전 검증 전까지 보존한다.
- 첫 설계: 원천/수집·제도/버전/회차·문서/조각·조건/질문·모델을 분리한다. ERD와 DDL은 DATABASE.md 및 database/ 아래에 작성한다.
- 개인정보는 현재 브라우저 암호화 보관을 유지한다. 회원·서버 프로필 동기화는 아직 구현 범위에 넣지 않는다.
- pgvector는 선택 확장 SQL로 준비하며 새 모델·차원과 네이티브 확장 환경을 확인한 뒤 적용한다. 별도 검색 서버 도입은 확정하지 않는다.
