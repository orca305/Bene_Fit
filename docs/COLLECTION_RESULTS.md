## 상세 및 필드 확인

- 복지로 중앙부처·지자체 각각 첫 10건의 상세를 조회했다. 전체 상세 수집은 아직 아니다.
- 두 표본 모두 지원대상·선정기준·지원내용 필드가 10/10건에 존재했다.
- 지자체 신청방법 내용은 7/10건에 존재했다.
- 중앙부처의 중첩 서비스 안내는 XML 원문 및 구조를 보존했다. 신청방법으로 자동 분류하지 않는다.
- 정부24 선정기준은 목록·상세 모두 1,048/10,898건에만 비어 있지 않았다.
- 정부24 상세 신청방법·구비서류는 10,898건 모두 비어 있지 않았다. 안내 문구만 있는 경우도 있어 정확성·충분성은 별도 확인해야 한다.
- 지자체 시군구는 4,102/4,837건에 존재했다. 시군구 공란을 오류나 전국 사업으로 자동 해석하지 않는다.

## 출처 비교

공백·기호를 제거한 이름의 정확 일치 기준:
- 출처 간 동명 후보 그룹: 743개
- 정부24 이름과 일치하지 않은 복지로 항목: 4,043건

동명은 실제 중복의 증거가 아니며, 미매칭은 실제 누락의 증거가 아니다.
기관·지역·원문·시점·대상 조건으로 검토한 뒤 연결해야 한다. 자동 병합은 하지 않았다.
정부24의 단순 대체재로 복지로를 제거하기 어렵다는 조사 근거로 사용한다.

## 산출물과 한계

- 실행·재개 안내: API_CHECK.md
- 로컬 요약: data/collection/summary.json
- 필드 충실도 및 정부24 ID 연결: data/collection/quality.json
- 중복·미매칭 후보: data/collection/comparison.json

- 오프라인 검증: scripts/check_apis.py --self-test, scripts/test_collection.py

데이터 및 인증키는 Git 제외. 키 값은 로그·보고서에 기록하지 않는다.
최초 목록 XML 표본은 평탄화 응답과 추출 행으로 저장했다. 반복 중첩 구조는 축약될 수 있다.
파서를 보완하여 이후 XML 요청 및 재조회한 복지 상세는 원문·중첩 구조도 보존한다.
목록 전체를 동시에 고정한 스냅샷은 아니며, 수집 중 원천 변경 가능성이 있다.
자격 규칙 승인·원문 근거 대조·파싱 정확도 평가는 아직 수행하지 않았다.
